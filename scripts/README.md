# Airlock Scripts

Helper scripts for running, testing, and managing Airlock.

## 🚀 Quick Start Scripts

### start.sh
Start Airlock Guard with test server (production mode)
```bash
./scripts/start.sh
```

### start-dev.sh
Start Airlock Guard in development mode (faster, no build)
```bash
./scripts/start-dev.sh
```

### stop.sh
Stop all Airlock processes
```bash
./scripts/stop.sh
```

## 🎯 Demo Scripts

### demo-attack.sh
Run the full attack demonstration (before/after comparison)
```bash
./scripts/demo-attack.sh
```

### getting-started.sh
Interactive getting started guide
```bash
./scripts/getting-started.sh
```

## 🔧 Utility Scripts

### verify-docker-setup.sh
Verify Docker configuration is correct
```bash
./scripts/verify-docker-setup.sh
```

### monitor.sh
Monitor Airlock logs in real-time
```bash
./scripts/monitor.sh
```

### start-secret-gate.sh
Start only the Secret Gate component
```bash
./scripts/start-secret-gate.sh
```
